# GamePadToKey - 高级需求规格说明书

## 1. 项目概述

### 1.1 项目背景
GamePadToKey 是一款 macOS 应用程序，旨在将 DualSense 无线控制器（PlayStation 5 手柄）转换为系统级的键盘和鼠标输入设备。该项目通过创新的分区映射系统，实现手柄按键的高效复用，让用户能够通过组合键激活不同的键盘区域，从而实现对完整键盘的无线控制。

### 1.2 项目愿景
- 将 DualSense 手柄转变为一个功能完整的键盘输入设备
- 通过分区映射系统解决手柄按键数量有限的问题
- 充分利用 DualSense 的先进功能提供丰富的操作反馈
- 提供灵活、可自定义的配置系统，满足不同用户需求

## 2. 分区映射系统

### 2.1 基本概念

#### 2.1.1 键盘分区模型
- **主分区**：整个键盘被划分为多个主分区（如字母区、数字区、功能区等）
- **子分区**：每个主分区可以进一步划分为更小的子分区
- **最小单元**：最小区是实际的按键映射单元，包含具体的键盘或鼠标按键

#### 2.1.2 分区层级
```
键盘 (Root)
├── 主分区 A (如：字母区)
│   ├── 子分区 A1 (如：左手区)
│   │   ├── 单元 A1-1 (A键)
│   │   ├── 单元 A1-2 (S键)
│   │   └── 单元 A1-3 (D键)
│   └── 子分区 A2 (如：右手区)
│       ├── 单元 A2-1 (J键)
│       ├── 单元 A2-2 (K键)
│       └── 单元 A2-3 (L键)
├── 主分区 B (如：数字区)
│   ├── 子分区 B1 (1-5键)
│   └── 子分区 B2 (6-0键)
└── 主分区 C (如：功能键区)
    ├── 子分区 C1 (F1-F4)
    └── 子分区 C2 (F5-F8)
```

### 2.2 分区激活机制

#### 2.2.1 组合键激活
- **激活方式**：通过 DualSense 上的组合键（如 L1 + R1 + △）激活特定分区
- **层级导航**：
  - 第一层组合键：激活主分区
  - 第二层组合键：在主分区内激活子分区
  - 第三层组合键：在子分区内激活更小的分区
- **退出机制**：
  - 自动超时退出
  - 使用特定组合键返回上一级
  - 使用取消键直接退出所有分区

#### 2.2.2 激活示例
```
默认状态
   ↓
L1 + R1 + △ → 激活字母区（主分区A）
   ↓
L1 + R1 + × → 激活左手区（子分区A1）
   ↓
L1 + R1 + □ → 激活更小的分区（如ASD区）
   ↓
△ → 映射到A键
```

### 2.3 映射类型

#### 2.3.1 键盘按键映射
- **单键映射**：一个手柄按键映射到一个键盘按键
- **组合键映射**：一个手柄按键映射到键盘组合键（如 Ctrl+C）
- **修饰键映射**：手柄按键作为修饰键使用
- **文本宏**：映射到预定义的文本字符串

#### 2.3.2 鼠标操作映射
- **鼠标移动**：摇杆控制鼠标移动
- **鼠标点击**：左键、右键、中键
- **鼠标滚动**：摇杆或触摸板控制滚动
- **拖拽操作**：组合键实现拖拽功能

### 3.2 配置文件元素详解

#### 3.2.1 分区定义
| 字段 | 类型 | 描述 | 必需 |
|------|------|------|------|
| id | string | 分区唯一标识符 | 是 |
| name | string | 分区显示名称 | 是 |
| type | string | main/sub/sub_sub | 是 |
| activationCombo | array | 激活组合键 | 是 |
| bounds | object | 在键盘上的区域范围 | 否 |
| feedback | object | 激活时的反馈设置 | 否 |
| children | array | 子分区列表 | 否 |
| mappings | array | 按键映射列表 | 否 |

#### 3.2.2 映射定义
| 字段 | 类型 | 描述 | 可选值 |
|------|------|------|--------|
| button | string | 手柄按钮 | triangle/circle/cross/square/L1/L2/R1/R2/L3/R3/up/down/left/right/touchpad/ps |
| action | string | 动作类型 | keyPress/keyCombo/modifier/mouseMove/mouseClick/mouseScroll |
| key | string | 键盘按键 | a-z, 0-9, f1-f12, etc. |
| modifiers | array | 修饰键 | shift/control/option/command |
| mode | string | 操作模式 | click/hold/toggle/absolute/relative |

#### 3.2.3 反馈定义
| 字段 | 类型 | 描述 |
|------|------|------|
| vibration | string | 振动模式 (none/light/medium/heavy/click/warning/continuous) |
| ledColor | string | LED颜色 (十六进制) |
| ledPattern | string | LED模式 (solid/pulse/blink/rainbow) |
| triggerEffect | string | 扳机效果 (none/halfPress/fullPress/stiff/smooth/feedback) |
| speaker | string | 音频文件路径 |

### 4.2 高级反馈系统

#### 4.2.1 自适应扳机反馈
- **力度反馈**：根据按键重要性提供不同阻力
- **边界指示**：在滚动到文档边界时扳机变硬
- **进度指示**：用扳机阻力表示进度（如音量、亮度）
- **模式指示**：不同分区使用不同的扳机手感

#### 4.2.2 LED反馈系统
- **分区指示**：不同分区使用不同颜色的LED
- **状态指示**：
  - 绿色：正常模式
  - 红色：特殊功能模式
  - 蓝色：鼠标控制模式
  - 黄色：系统控制模式
- **动态效果**：
  - 呼吸效果：等待输入状态
  - 闪烁效果：操作确认
  - 彩虹效果：特殊模式
  - 渐变效果：模式切换

#### 4.2.3 触觉反馈
- **按键确认**：每次按键提供微振动确认
- **边界反馈**：到达分区边界时提供触觉提示
- **模式切换**：切换模式时的特殊振动模式
- **错误提示**：无效操作的触觉提示

#### 4.2.4 音频反馈
- **系统通知**：通过手柄扬声器播放系统通知
- **按键音**：可选的按键音效
- **语音提示**：当前分区的语音播报
- **自定义音频**：用户可导入自定义音效

### 4.3 智能功能

#### 4.3.1 上下文感知
- **应用特定配置**：不同应用自动切换配置

protocol InputSimulator {
    func simulateKeyPress(key: KeyCode, modifiers: [Modifier])
    func simulateMouseMove(dx: Double, dy: Double)
    func simulateMouseClick(button: MouseButton)
    func simulateMouseScroll(delta: Double, axis: ScrollAxis)
}

class SystemWideInputSimulator: InputSimulator {
    private let eventTap: CFMachPort
    private let runLoop: CFRunLoop
    
    func simulateKeyPress(key: KeyCode, modifiers: [Modifier]) {
        // 使用CGEvent创建系统级键盘事件
        let eventSource = CGEventSource(stateID: .combinedSessionState)
        let keyDown = CGEvent(keyboardEventSource: eventSource, 
                             virtualKey: key.rawValue, 
                             keyDown: true)
        keyDown?.flags = modifiers.reduce(into: CGEventFlags()) { $0.insert($1.cgFlag) }
        keyDown?.post(tap: .cghidEventTap)
        
        // 自动发送keyUp
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.05) {
            let keyUp = CGEvent(keyboardEventSource: eventSource, 
                               virtualKey: key.rawValue, 
                               keyDown: false)
            keyUp?.post(tap: .cghidEventTap)
        }
    }
}

    private var triggerController: AdaptiveTriggerController
    private var audioEngine: AudioEngine

            await withTaskGroup(of: Void.self) { group in
                if let vibration = feedback.vibration {

                        await self.vibrationEngine.play(vibration)
                    }
                }
                
                if let ledColor = feedback.ledColor {
                    group.addTask {
                        await self.ledController.setColor(ledColor, 
                                                          pattern: feedback.ledPattern)
                    }
                }
                
                if let triggerEffect = feedback.triggerEffect {
                    group.addTask {
                        await self.triggerController.applyEffect(triggerEffect)
                    }
                }
                
                if let audioFile = feedback.audioFile {
                    group.addTask {
                        await self.audioEngine.play(audioFile)
                    }
                }
            }
        }
    }
}
